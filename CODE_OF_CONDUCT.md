# Code of Conduct

OpenSpace adopts the [Contributor Covenant, version 2.1][cc] as its code of
conduct. By participating in this project — contributing code, opening
issues, reviewing pull requests, or interacting in any project space — you
agree to abide by it.

The full text is available at:

<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

## Scope

This code applies in all project spaces — the GitHub repository, issues
and pull requests, discussions, release notes, and any communication
channel a maintainer designates as a project space — and in any space
where an individual is representing the project.

## Reporting

Reports of unacceptable behaviour can be sent privately to the maintainer
listed in [`LICENSE`](LICENSE). Reports will be reviewed and investigated
promptly and fairly.

All maintainers are obligated to respect the privacy and security of the
reporter of any incident.

## Enforcement

Maintainers will follow the [Community Impact Guidelines][cig] published
with the Contributor Covenant when determining the consequences for any
action they deem in violation.

[cc]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
[cig]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines
