## [Unreleased]

### Added

- `AGENTS.md` declaring the Agent skills layout for AI coding agents.
- `docs/agents/issue-tracker.md` documenting the GitHub Issues workflow.
- `docs/agents/triage-labels.md` mapping the canonical triage roles.
- `docs/agents/domain.md` describing the multi-context domain doc layout.
- `README.md` with project overview, status, repository layout, and a
  documentation map.
- `CONTEXT-MAP.md` indexing all glossaries in the repository.
- `CONTEXT.md` with the App-level glossary and anti-vocabulary table.
- `CONTRIBUTING.md` with branching, commit, and project policy
  conventions.
- `SECURITY.md` with the vulnerability reporting policy.
- `CODE_OF_CONDUCT.md` adopting Contributor Covenant 2.1.
- `docs/architecture.md` sketching the layered, fractal feature layout
  and Client triplet pattern.
- `docs/roadmap.md` with phased delivery plan and exit criteria.
- `docs/adr/README.md` introducing the ADR practice and index.
- ADR 0001: record architectural decisions in this repository.
- ADR 0002: adopt the Composable Architecture for state management.
- ADR 0003: use SwiftData for on-device persistence.
- ADR 0004: target iOS 17.6 as the minimum deployment.
- ADR 0005: use Swift Testing as the unit-testing framework.
